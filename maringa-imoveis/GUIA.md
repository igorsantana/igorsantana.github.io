# Como usar o mapa de imóveis em Maringá

**Acesse:** https://igorsantana.github.io/maringa-imoveis/

---

## Primeiro passo

Ao abrir a página, você verá o mapa de Maringá e um botão **Carregar imóveis**.

Clique nesse botão para buscar os anúncios. Os pontos coloridos aparecem aos poucos no mapa — não é preciso esperar terminar para começar a explorar.

Enquanto carrega, um pequeno painel no canto mostra o progresso e quantos imóveis já foram encontrados.

---

## O que cada coisa significa

### Pontos no mapa

Cada ponto é um imóvel à venda (casa ou apartamento) em Maringá. Clique em um ponto para ver:

- tipo (casa ou apartamento)
- preço pedido
- preço por m² (quando disponível)
- área, dormitórios e endereço
- link para o anúncio no SUB100

### Painel à esquerda

| Opção | O que faz |
| --- | --- |
| **Pontos** | Mostra cada imóvel como um círculo no mapa |
| **Mapa de calor** | Concentração de anúncios (ou preço por m²) em regiões |
| **Preço / R$/m² / Tipo** | Define a cor dos pontos |
| **Tipo** | Marque ou desmarque Casa e Apartamento |
| **Dormitórios** | Filtra por quantidade mínima de quartos |
| **Bairro** | Mostra só um bairro |
| **Faixa de preço** | Preço mínimo e máximo em reais |

Os números no rodapé do painel (imóveis, preço mediano, R$/m² mediano) mudam conforme os filtros.

### Cores no mapa

- **Verde** → preços mais baixos na faixa selecionada  
- **Vermelho** → preços mais altos  
- No modo **Tipo**, azul = apartamento, laranja = casa  

---

## Sobre os preços

- Os valores são de **anúncio** (o que o vendedor pede), não de venda fechada.
- Fonte: portal [SUB100](https://sub100.com.br).
- O mapa não faz contato com imobiliárias; para comprar ou visitar, use o link **Ver anúncio** no popup de cada ponto.

---

## Problemas comuns

| Situação | O que tentar |
| --- | --- |
| Mapa em branco, sem botão | Atualize a página (F5) |
| Erro ao carregar | Verifique sua internet e clique em **Tentar novamente** |
| Poucos pontos após filtrar | Afrouxe os filtros (bairro, preço, dormitórios) |
| Mapa de fundo cinza | Aguarde alguns segundos; os tiles do mapa podem estar carregando |

---

## Dúvidas sobre o site em si

Este mapa é um projeto pessoal de visualização de dados públicos de anúncios. Não é o site oficial do SUB100 nem de imobiliárias.
